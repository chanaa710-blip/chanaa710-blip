### 🌉 Bridge — Community Assistance Platform

A full-stack community platform designed to connect people who need assistance with nearby volunteers.

The system enables users to create and manage requests, discover relevant help based on location and categories, and interact through an intuitive interface.

Built with a focus on clean architecture, scalable backend design, and usability.

---

### 🎓 Student Grants Management System

A backend-focused full-stack application for managing student grant applications, built with Node.js, Express, and MongoDB.

The system provides secure authentication, grant application workflows, document management, and administrator tools for reviewing and processing applications.

Students can register, complete multi-step applications, upload supporting documents, save drafts, and track application status.

Administrators can review applications, filter and sort requests, approve or reject submissions, and automatically notify applicants by email.

**Technologies:** Node.js, Express, MongoDB, Mongoose, JWT, bcrypt, Multer, Nodemailer, React, Vite
